    Por comprar

      Preavisos

      Cuándo quieres que te avisen antes de que caduque algo. Pon 0 días para el mismo día. La hora es la del aviso. Vale para todas las caducidades.

      Avisos en el móvil

      Abrir en ntfy

      Instala la app ntfy en cada móvil, añade este canal y pulsa «Enviar aviso de prueba». Los avisos automáticos los envía el programador de GitHub (mira el LEEME).

      Sincronización

      Solo en este móvil

      Pega la configuración de tu proyecto de Firebase (o el código de conexión que te pase el otro móvil).

      Para conectar el otro móvil (y el programador de GitHub) copia este código y pégalo allí. Es privado: quien lo tenga puede ver y cambiar vuestros datos.
